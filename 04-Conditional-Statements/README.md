# Conditional Statements in Java

Conditional statements allow a Java program to make decisions based on whether a condition is `true` or `false`.

They control which block of code executes depending on the given condition.

## Learning Objectives

By studying these topics, you will learn how to:

- Make decisions using conditions.
- Execute different blocks of code depending on a condition.
- Handle multiple possible conditions.
- Use `switch` to select among different cases.
- Write clear and readable conditional logic.
