## 1. Meet Java

**Java is a high-level, general-purpose, class-based, object-oriented programming language** designed to help developers build reliable, portable, and scalable software.

Created by **James Gosling and his team at Sun Microsystems**, Java was first released publicly in **1995**. Today, it is used across enterprise software, backend systems, financial services, developer tools, and many other applications.

Java's philosophy is simple: **write your code once, and run it wherever a compatible Java Virtual Machine (JVM) is available.**

That's the idea behind its famous slogan:

> *Write Once, Run Anywhere.*

## 2. Why Is Java Special?

Here are some of the features that make Java worth learning:

* **Platform Independent** — Java source code is compiled into bytecode that can run on compatible JVMs across different operating systems.
* **Object-Oriented** — Classes and objects help organize code into reusable, maintainable components.
* **Strongly Typed** — Java checks types to catch many mistakes before a program runs.
* **Automatic Memory Management** — Garbage collection helps reclaim memory occupied by objects that are no longer needed.
* **Multithreading** — Java provides tools for running multiple tasks concurrently.
* **Rich Ecosystem** — Libraries, frameworks, and developer tools support everything from small programs to large applications.
* **Robust and Mature** — Java offers exception handling, type checking, and a mature runtime environment for building dependable software.

## 4. How Does Java Work?

One of Java's most interesting features is its execution process.

```text
Your Java Code
    HelloWorld.java
         |
         v
   Java Compiler
       (javac)
         |
         v
    Bytecode
    HelloWorld.class
         |
         v
 Java Virtual Machine
        (JVM)
         |
         v
   Program Executes
```

**The journey in four steps:**

1. **Write** — Create your program in a `.java` source file.
2. **Compile** — The Java compiler (`javac`) converts the source code into bytecode.
3. **Load and execute** — The JVM loads and executes the bytecode, using interpretation and/or just-in-time compilation as appropriate.
4. **See the result** — Your program produces its output.
