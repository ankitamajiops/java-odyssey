# Loops in Java

Loops are control-flow statements that allow a program to execute a block of code repeatedly while a condition is satisfied or for a specified number of iterations.

Loops reduce code repetition and make programs more efficient and easier to maintain.

## Learning Objectives

After completing this section, you should be able to:

- Explain why loops are used in Java.
- Use `while`, `do-while`, and `for` loops.
- Iterate through arrays and other iterable data using enhanced `for` loops.
- Create nested loops for patterns and repeated operations.
- Control loop execution using `break` and `continue`.
- Recognize and prevent unintended infinite loops.
- Select an appropriate loop for a given problem.
