# Operators in Java

Operators are symbols that perform operations on variables and values. They are used in calculations, comparisons, logical decisions, and many other programming tasks.

This section covers the main types of operators in Java, with examples and explanations suitable for beginners.

## Learning Objectives

By completing this section, you will learn to:

- Perform mathematical calculations using arithmetic operators.
- Compare values using relational operators.
- Combine conditions using logical operators.
- Update variables using assignment operators.
- Understand unary, bitwise, and shift operations.
- Use the ternary operator for concise conditional expressions.
- Check object types using `instanceof`.
- Understand operator precedence and associativity when evaluating expressions.

## Why Operators Matter

Operators are essential for writing Java programs that calculate results, compare values, make decisions, and manipulate data. Understanding them provides a foundation for conditional statements, loops, arrays, and problem-solving with Java.
